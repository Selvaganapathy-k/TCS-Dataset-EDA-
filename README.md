
# 📊 TCS Dataset – Exploratory Data Analysis (EDA)

## 📌 Project Description

This project performs **Exploratory Data Analysis (EDA)** on the **TCS (Tata Consultancy Services) dataset**.
The main objective is to analyze historical data, understand trends, patterns, and statistical characteristics using Python data analysis techniques.

This project is developed as a **mini project** to strengthen understanding of EDA concepts and data visualization.

---

## 📁 Dataset Information

* **Dataset Name:** TCS Dataset
* **Source:** Public / academic dataset

The dataset typically includes:

* Date / Time information
* Open, High, Low, Close prices
* Volume and other market-related attributes

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Selvaganapathy-k/TCS-Dataset-EDA-
cd TCS-Dataset-EDA-
```

---

### 2️⃣ (Optional) Create Virtual Environment

```bash
python -m venv venv
```

Activate the environment:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

---

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

### 4️⃣ Run the Notebook

```bash
jupyter notebook
```

Open:

```
dataset.ipynb
```
